# Glossary — peta-hono

Ubiquitous language for the DSL, validation, OpenAPI, auth, and error contexts. Keep this file as the source of truth for naming; ADRs reference these terms.

| Term | Context | Definition |
|------|---------|------------|
| **ApiBuilder** | DSL | Closure returned by `createApi<Auth,Env>()` holding `app`, `auths`/`authSchemes` maps, `opts`. Facade over `OpenAPIHono`. The `setup.ts` singleton is the protectable pattern. |
| **RouteFields** | DSL | High-level generic config `{method, path:P, body?:B, query?:Q, headers?:H, responses?, tags?, summary?, operationId?, deprecated?}` with ArkType generics for handler inference. User-facing. |
| **RouteConfig** | OpenAPI | Low-level `{method, path, request, responses, security, middleware, status, operationId, deprecated}` consumed by `OpenAPIHono.openapi()`. |
| **StoredRoute** | OpenAPI | Persisted `{method, oapiPath, config, handler}` appended to `_routes` in insertion order. |
| **PARAM_TOKEN_RE** | Routing (paths) | Shared constant `/:([a-zA-Z0-9_]+)(?:\{[^}]+\})?(\?)?/g` + `PARAM_HAS_RE` non-global for `.test`. Single source for param parsing (ADR-010). `src/paths.ts` canonical. |
| **Method / HttpMethod / normalizeMethod** | Routing (paths) | `SUPPORTED_METHODS=["GET","POST","PUT","PATCH","DELETE"]`, `HttpMethod` union, `Method = HttpMethod \| Lowercase<HttpMethod> \| (string & {})` (autocomplete), `normalizeMethod(m:string): Lowercase<HttpMethod>` case-insensitive ("GET"/"get"/"Get" → "get", throws `Unsupported method`). Pure in `src/paths.ts`, re-exported via `src/openapi.ts` and public barrel `src/index.ts` (`import { normalizeMethod } from "peta-hono"` per CHANGELOG 0.5.0). |
| **ParamToken** | DSL / OpenAPI | Parsed `{name:string, optional:boolean}` from Hono tokens `:name`, `:name?`, `:name{regex}`, `:name{regex}?`, `*→{wildcard}`. Via `parseParamTokens(path)` over `PARAM_TOKEN_RE`. |
| **ParamsFromPath** | DSL (type) | Type-level `ParamRecord` intersection deriving flat param keys from `P extends string`. `"/posts/:id"` → `{id:string}`, `"/hello/:name?"` → `{name?:string}`. |
| **ReqFor** | DSL (type) | Handler req type `ParamsFromPath<P> & {body?:B}&{query?:Q}&{headers?:H}&{c:Context<E>} & AuthField<Auth>`. Flat Encore-style. |
| **AuthField** | DSL (type) | Conditional `{auth:Auth}` present only when `Auth≠undefined`. Controls `req.auth` presence. |
| **ApiMethodHelper** | DSL (type) | Explicit shorthand helper `type ApiMethodHelper<Auth,E> = { <P,B,Q,H>(path, config & {auth?:undefined}, handler: ReqFor)=>void; <P,B,Q,H>(path, config & {auth:string}, handler: ReqFor & AuthField<Auth>)=>void }`. Not `ReturnType<typeof makeMethodHelper>` — preserves both overloads so `createApi<undefined>` → `api.get("/x", {auth:"required"}, ({auth})=>...)` errors (handler `auth` missing). Fixed grilling 02; see ADR-009. |
| **AuthRegistration** | Auth | `Map<string,MiddlewareHandler>` entry from `auth(name,(c:Context<E>)=>Auth,scheme?)` — wraps return-based fn via `c.set("auth",ctx)`. |
| **AuthScheme** | Auth / OpenAPI | Union `http bearer/basic` or `apiKey {in,name}`. Emitted to `components.securitySchemes`; drives Scalar lock icons. |
| **ArkType** | Validation | `Type<any,any>` alias with callable validation `schema(data)=>data\|ArkErrors` and `toJsonSchema()`. Peer dep `arktype@^2.2.1`. |
| **ArktypeValidator** | Validation | `validator(target, fn)` middleware factory that runs `coerceDeep` then `schema(data)` and **throws `APIError(400)`** on `ArkErrors` (never returns `Response`). |
| **Coercion** | Validation | `coerceDeep(schema,data)`/`coerceValue(prop,raw,defs)` deep walk via `JsonSchema` translating query/header strings → numbers/booleans/arrays before validation; preserves `undefined`/empty-string for 400. Handles nested objects, `number[]` single-wrap, `boolean "true"/"false"` strictly. **Header invariant:** Hono lowercases incoming header keys via Fetch `Headers`; `coerceDeep` does NOT auto-lowercase — declare `type({ "x-api-key": "string" })` not `"X-Api-Key"` (strict fail-fast 400). Proposed `src/validation.ts`. |
| **OapiPath** | OpenAPI | OpenAPI form `/{param}` derived via `toOapiPath(path)` — `:x`→`{x}`, `:x{regex}`→`{x}`, `:x?`→`{x}`, `*`→`{wildcard}`. `src/paths.ts` pure; header lowercasing is NOT here (see Coercion/ArktypeValidator ponytail — `_addObjectParams`). Used as `paths` key. |
| **OperationId** | OpenAPI | Unique per operation; default `method_oapiPath` (`/`→`_`, `{}` stripped). Custom via `config.operationId`; dedup suffix `_2`,`_3` via `seenOperationIds:Set` + `baseCounts:Map`. |
| **ComponentRegistry** | OpenAPI | `{schemas:Map<string,JsonSchema>, securitySchemes:Map<string,AuthScheme>}` hoisting `$defs` to stable names. |
| **Stable hash name** | OpenAPI | `schema_<sha1Hex(normalizeRefs(JSON.stringify(def))).slice(0,12)>` — content-hash over normalized structure, not ArkType counter `intersection216`. Via Web Crypto SHA-1. |
| **RewriteRefs** | OpenAPI | Recursive in-place `#/$defs/X` → `#/components/schemas/schema_<hash>` rewriting (`rewriteRefs(node,rename)`). Handles objects + arrays. |
| **DocsMount** | OpenAPI | `docs(specPath,uiPath)` binding — `app.doc(specPath,{openapi:"3.0.0",info})` + `app.get(uiPath, apiReference({spec:{url:specPath}}))`. Overload `(specPath?,uiPath?)` or `({specPath?,uiPath?})`. Must be called after side-effect route imports. |
| **APIError** | Error | `class APIError extends Error {status:ContentfulStatusCode, message}` — typed HTTP error thrown everywhere, rendered by single `onError` chokepoint. |
| **fail / errors / httpErrors** | Error | Helpers `fail.notFound(msg?)→APIError(404,msg)` — 11 codes: 400,401,403,404,409,422,429,500,502,503,504. `errors===fail`, `httpErrors===fail`. |
| **ErrorHandler** | Error | `createErrorHandler(debug?) => (err,c)=>Response` (proposed `src/errors.ts` kernel). `APIError→c.json({error},status)` else `console.error` + prod-gated `debug && !isProd` shows `{error,stack}` else generic 500. Single chokepoint (ADR-005). |
| **Ponytail** | Cross-cutting | `// ponytail: ...` marker — deliberate simplification with documented `ceiling/upgrade path`. Examples: 404 heuristic, `400` on `:param` auto-doc (guard `if(!responses["400"])` respects explicit `responses:{400}`, benign false-positive), header lowercasing (`_addObjectParams` lowercases when `in==="header"`; `toOapiPath` no longer claims header ponytail — Fetch Headers fact), `dispatch` cast, `*→{wildcard}`. |
| **Hono Env** | DSL / Error | Generic `Env` (`{Variables,Bindings}`) threaded through `Context<E>` via `createApi<Auth,Env>` → `ReqFor.c` and `auth` middleware `(c:Context<E>)=>Auth`. Enables `c.var.session`, `c.env`. |
| **Spec snapshot** | Tooling | Golden `examples/blog/spec.snapshot.json` — `JSON.stringify(spec,null,2)` asserted in `blog/selfcheck.ts`. Regenerate: `rm spec.snapshot.json && nub examples/blog/selfcheck.ts`. Excluded from Biome via `overrides`. |
