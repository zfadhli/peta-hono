# Glossary — peta-hono

Ubiquitous language for the DSL, validation, OpenAPI, auth, and error contexts. Keep this file as the source of truth for naming; ADRs reference these terms.

| Term | Context | Definition |
|------|---------|------------|
| **ApiBuilder** | DSL | Closure returned by `createApi<Auth,Env>()` holding `app`, `auths`/`authSchemes` maps, `opts`. Facade over `OpenAPIHono`. The `setup.ts` singleton is the protectable pattern. |
| **RouteFields** | DSL | High-level generic config `{method, path:P, body?:B, query?:Q, headers?:H, responses?, tags?, summary?, operationId?, deprecated?, status?, hide400?}` with ArkType generics for handler inference. User-facing. |
| **RouteConfig** | OpenAPI | Low-level `{method, path, request, responses, security, middleware, status, operationId, deprecated, hide400}` consumed by `OpenAPIHono.openapi()`. |
| **StoredRoute** | OpenAPI | Persisted `{method, oapiPath, config, handler}` appended to `_routes` in insertion order. |
| **PARAM_TOKEN_RE** | Routing (paths) | Shared constant `/:([a-zA-Z0-9_]+)(?:\{[^}]+\})?(\?)?/g` + `PARAM_HAS_RE` non-global for `.test`. Single source for param parsing (ADR-010). `src/paths.ts` canonical. |
| **Method / HttpMethod / normalizeMethod** | Routing (paths) | `SUPPORTED_METHODS=["GET","POST","PUT","PATCH","DELETE"]`, `HttpMethod` union, `Method = HttpMethod \| Lowercase<HttpMethod> \| (string & {})` (autocomplete), `normalizeMethod(m:string): Lowercase<HttpMethod>` case-insensitive ("GET"/"get"/"Get" → "get", throws `Unsupported method`). The `(string & {})` escape hatch means a typo like `"GETT"` passes typecheck but **throws at runtime** via `normalizeMethod` — the enforcement point. Pure in `src/paths.ts`, re-exported via `src/openapi.ts` and public barrel `src/index.ts` (`import { normalizeMethod } from "peta-hono"` per CHANGELOG 0.5.0). |
| **ParamToken** | DSL / OpenAPI | Parsed `{name:string, optional:boolean}` from Hono tokens `:name`, `:name?`, `:name{regex}`, `:name{regex}?`, `*→{wildcard}`. Via `parseParamTokens(path)` over `PARAM_TOKEN_RE`. |
| **ParamsFromPath** | DSL (type) | Type-level `ParamRecord` intersection deriving flat param keys from `P extends string`. `"/posts/:id"` → `{id:string}`, `"/hello/:name?"` → `{name?:string}`. |
| **ReqFor** | DSL (type) | Handler req type `ParamsFromPath<P> & {body?:B}&{query?:Q}&{headers?:H}&{c:Context<E>} & AuthField<Auth>`. Flat Encore-style. If you see `Property 'auth' does not exist on type 'ReqFor<...>'`, the route config is missing `auth: "required"` (issue #11) — add it. |
| **AuthField** | DSL (type) | Conditional `{auth:Auth}` present only when `Auth≠undefined`. Controls `req.auth` presence. |
| **ApiMethodHelper** | DSL (type) | Explicit shorthand helper `type ApiMethodHelper<Auth,E> = { <P,B,Q,H>(path, config & {auth?:undefined}, handler: ReqFor)=>void; <P,B,Q,H>(path, config & {auth:string}, handler: ReqFor & AuthField<Auth>)=>void }`. Not `ReturnType<typeof makeMethodHelper>` — preserves both overloads so `createApi<undefined>` → `api.get("/x", {auth:"required"}, ({auth})=>...)` errors (handler `auth` missing). Fixed grilling 02; see ADR-009. |
| **AuthRegistration** | Auth | `Map<string,MiddlewareHandler>` entry from `auth(name,(c:Context<E>)=>Auth,scheme?)` — wraps return-based fn via `c.set("auth",ctx)`. |
| **AuthScheme** | Auth / OpenAPI | NARROW security-scheme input to `auth(name, mw, scheme?)` — union `http bearer/basic` or `apiKey {in:`header`|`query`, name}` (unchanged since v0.5.4). When `auth(name,mw)` is registered WITHOUT a `scheme`, a default `{type:"http",scheme:"bearer"}` is published (issue #03) so a `{auth}` route is always documented protected. Keeping it narrow means an exhaustive switch over it stays valid even as the library emits more scheme kinds. |
| **SecurityScheme** | Auth / OpenAPI | WIDE emitted type of `components.securitySchemes` — `AuthScheme | apiKey {in:`cookie`, name} | oauth2 {flows.authorizationCode}`. Use it when *reading* the emitted spec; use `AuthScheme` when *passing* a scheme to `auth()`. |
| **AuthStrategy** | Auth | Handle returned by `auth.session/jwt/oauth/strategy(name, opts)` — groups a guard middleware (optional), an OpenAPI scheme, and flow helpers. Strategies are opt-in and register through the same path as `auth(name,mw,scheme?)`. |
| **SessionStrategy** | Auth | Cookie-session strategy: signed `sid.hmac` cookie + pluggable `SessionStore`; guard yields the session payload as `req.auth`. Helpers: `create(c,data)` (sets cookie AND returns the `Set-Cookie` value), `destroy(c)`, `get(c)`, `generateCsrf(c)`, `verifyCsrf(c, token)`. Cookie is `Secure` by default (dev-over-http opt-out via `cookie.secure: false`); `hostPrefix` renames to `__Host-sid`. |
| **SessionCsrf** | Auth | `csrf: "origin" | "double-submit" | false` (default `"origin"`). `"origin"` rejects a cross-site mutating request (mismatched `Origin` / `Sec-Fetch-Site: cross-site` → 403) with no client token. `"origin"` mode is only valid with the `origin` option set (`string | string[]`) — the strategy throws if `origin` is omitted. `"double-submit"`/`true` keeps the `x-csrf-token` behavior; `false` restores legacy. |
| **JwtStrategy** | Auth | Access-token (via `jose` `SignJWT`/`jwtVerify`) + opaque rotating refresh-token strategy; guard verifies the `Bearer` access token. Helpers: `issue(sub,claims?,c?)`, `refresh(refreshToken,c?)`, `revoke(refreshToken,c?)`, `verifyAccess(token)`. `algorithms` pins the `alg` (default `["HS256"]`; must include the signing alg); `keys`/`kid` rotation, `jwks`, and asymmetric (RS256/EdDSA) are opt-in; `refreshTransport` sets/clears an HttpOnly refresh cookie via `CookieTransport`. Refresh tokens are single-use & family-revoked on reuse. |
| **OAuthStrategy** | Auth | Google authorization-code + PKCE flow; emits an `oauth2` scheme, mounts `/start`+`/callback`. PKCE is on by default (even for confidential clients with `clientSecret`); the state cookie is `Secure` by default; a provider `error` param is routed to `onError`. Helpers: `authorizeUrl(state, codeChallenge?)`, `exchangeCode(code, verifier?)`, `getUser(tokens)`, `mount(app)`. `onSuccess` is the only integration point. |
| **CookieTransport** | Auth | `createCookieTransport(opts)` → `{ read(c), set(c,value), clear(c) }` for an opaque bearer token (e.g. a refresh token) in an HttpOnly cookie. Defaults to HttpOnly + Secure + SameSite=Lax, path-scoped, and **`hostPrefix: false`** (deliberate — lets `path` scoping work; set it only when you want the `__Host-` rename). `hostPrefix: true` renames to `__Host-<name>` **and forces `Path=/`**, so a non-`/` `path` requires omitting `hostPrefix` (use `secure` + `securePrefix` for the `__Secure-` variant at a non-`/` path). Re-exported from the barrel. |
| **PasswordHelper** | Auth (opt-in) | Opt-in `peta-hono/password` subpath — `hashPassword(password, opts?)` / `verifyPassword(hash, password)` backed by `@noble/hashes` scrypt. Returns a self-describing, parameter-encoded hash (work factors + salt + derived key) with constant-time verification. `ponytail:` credential hashing only — no user/password/session management (caller's job). Default work factors `N=2**15, r=8, p=1, dkLen=32`; scrypt default because argon2id is ~5× slower in pure JS. |
| **CookieSerializeOptions** | Auth | `{ maxAge?, path?, httpOnly?, secure?, sameSite?, domain?, priority?, hostPrefix?, securePrefix? }`. `hostPrefix` renames `__Host-<name>` + forces `Secure`/`Path=/`/no `Domain`; `securePrefix` renames `__Secure-<name>` (requires `Secure`, does not force `Path=/`); `SameSite="None"` requires `Secure` (RFC-6265bis). |
| **SessionStore** | Auth | `get/set/delete(sid)` abstraction for the session payload. In-memory adapter: `createMemorySessionStore()`. |
| **RefreshTokenStore** | Auth | `get/save/delete/getFamily/deleteFamily()` abstraction keyed by token hash. In-memory adapter: `createMemoryRefreshTokenStore()`. |
| **ArkType** | Validation | `Type<any,any>` alias with callable validation `schema(data)=>data\|ArkErrors` and `toJsonSchema()`. Peer dep `arktype@^2.2.1`. |
| **ArktypeValidator** | Validation | `validator(target, fn)` middleware factory that runs `coerceDeep` then `schema(data)` and **throws `APIError(400)`** on `ArkErrors` (never returns `Response`). Lives in `src/validation.ts` (ADR-011 step 3). |
| **Coercion** | Validation | `coerceDeep(schema,data)`/`coerceValue(prop,raw,defs)` deep walk via `JsonSchema` translating query/header strings → numbers/booleans/arrays before validation; preserves `undefined`/empty-string for 400. Handles nested objects, `number[]` single-wrap, `boolean "true"/"false"` strictly. **Header invariant:** Hono lowercases incoming header keys via Fetch `Headers`; `coerceDeep` does NOT auto-lowercase — declare `type({ "x-api-key": "string" })` not `"X-Api-Key"` (strict fail-fast 400). Proposed `src/validation.ts` — **implemented 2026-09-02 (ADR-011 step 3)**. |
| **OapiPath** | OpenAPI | OpenAPI form `/{param}` derived via `toOapiPath(path)` — `:x`→`{x}`, `:x{regex}`→`{x}`, `:x?`→`{x}`, `*`→`{wildcard}`. `src/paths.ts` pure; header lowercasing is NOT here (see Coercion/ArktypeValidator ponytail — `addObjectParams` in `src/spec.ts`). Used as `paths` key. |
| **OperationId** | OpenAPI | Unique per operation; default `method_oapiPath` (`/`→`_`, `{}` stripped). Custom via `config.operationId`; dedup suffix `_2`,`_3` via `seenOperationIds:Set` + `baseCounts:Map`. |
| **ComponentRegistry** | OpenAPI | `{schemas:Map<string,JsonSchema>, securitySchemes:Map<string,SecurityScheme>}` hoisting `$defs` to stable names. Aggregate lives in `src/spec.ts` (ADR-011 step 5); `src/registry.ts` operates on the structural `SchemaHost` (`{ schemas }`) half. |
| **Stable hash name** | OpenAPI | `schema_<sha1Hex(normalizeRefs(JSON.stringify(def))).slice(0,12)>` — content-hash over normalized structure, not ArkType counter `intersection216`. Via Web Crypto SHA-1. |
| **RewriteRefs** | OpenAPI | Recursive in-place `#/$defs/X` → `#/components/schemas/schema_<hash>` rewriting (`rewriteRefs(node,rename)`). Handles objects + arrays. |
| **DocsMount** | OpenAPI | `docs(specPath,uiPath)` binding — `app.doc(specPath,{openapi:"3.0.0",info})` + `app.get(uiPath, apiReference({spec:{url:specPath}}))`. Overload `(specPath?,uiPath?)` or `({specPath?,uiPath?,auth?})`. `auth` (optional) gates both routes — a raw `MiddlewareHandler` or a registered auth name — registered **before** mounting (Hono matches in registration order; `app.use` after `app.get` would not guard). The spec builds **lazily** on the `/openapi.json` request; what matters for correctness is **route registration order** (Hono matches in order), so call `docs()` after route imports for clarity. |
| **APIError** | Error | `class APIError extends Error {status:ContentfulStatusCode, message}` — typed HTTP error thrown everywhere, rendered by single `onError` chokepoint. |
| **fail** | Error | Canonical helper `fail.notFound(msg?)→APIError(404,msg)` — 11 codes: 400,401,403,404,409,422,429,500,502,503,504. `errors` / `httpErrors` are **deprecated pure synonyms** (keep `fail`). |
| **ErrorHandler** | Error | `createErrorHandler(debug?) => (err,c)=>Response` (`src/errors.ts` kernel). `APIError→c.json({error},status)` else `console.error` + dev-gated `debug && (NODE_ENV==="development"||"test")` shows `{error,stack}` else generic 500. Debug is **dev-only** — withholds details unless NODE_ENV is explicitly development/test (safe default is redact, issue #06). Single chokepoint (ADR-005). |
| **Ponytail** | Cross-cutting | `// ponytail: ...` marker — deliberate simplification with documented `ceiling/upgrade path`. Examples: 404 heuristic, `400` on `:param` auto-doc (guard `if(!responses["400"])` respects explicit `responses:{400}`; `hide400` opt-out built 2026-08-27 issue #05), header lowercasing (`addObjectParams` in `src/spec.ts` lowercases when `in==="header"`; `toOapiPath` no longer claims header ponytail — Fetch Headers fact), `dispatch` cast, `*→{wildcard}`. |
| **Hono Env** | DSL / Error | Generic `Env` (`{Variables,Bindings}`) threaded through `Context<E>` via `createApi<Auth,Env>` → `ReqFor.c` and `auth` middleware `(c:Context<E>)=>Auth`. Enables `c.var.session`, `c.env`. |
| **Spec snapshot** | Tooling | Golden `examples/blog/spec.snapshot.json` — `JSON.stringify(spec,null,2)` asserted in `blog/selfcheck.test.ts`. Regenerate: `rm spec.snapshot.json && nub run test`. Excluded from Biome via `overrides`. |
